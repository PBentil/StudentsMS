# Student Management API

A RESTful Student Management API built with **ASP.NET Core Web API**, **Entity Framework Core**, and **PostgreSQL**.

This project demonstrates backend development concepts including CRUD operations, database integration, dependency injection, and API architecture.

---

## 🚀 Technologies Used

- C#
- ASP.NET Core Web API (.NET 10)
- Entity Framework Core
- PostgreSQL
- Npgsql
- REST API
- Dependency Injection

---

## 📌 Features

### Student Management

- Create a student
- Retrieve all students
- Retrieve a student by ID
- Update student information
- Delete a student
